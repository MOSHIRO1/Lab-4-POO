# ArenaGT – Lab 4 Polimorfismo (CC2008)

Aplicación de consola en Java para administrar las copas deportivas entre empresas de ArenaGT:
participantes, torneos de cinco disciplinas (fútbol sala, fútbol sala con penales, baloncesto,
voleibol y relevos), inscripciones, calendario, resultados, tablas de posiciones, premios y reportes.

## Requisitos

- JDK 17 o superior (probe con JDK 21).

## Compilar

Desde la carpeta raíz del repositorio:

```bash
javac -encoding UTF-8 -d bin src/*.java
```

## Ejecutar

```bash
java -cp bin Main
```
